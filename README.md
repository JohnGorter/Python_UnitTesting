# Python_UnitTesting

Materiaal over unit testing met Python: demo's, labs en slides.

## Inhoud

- `_demos/` - voorbeeldcode
- `_labs/` - oefeningen
- `_slides/` - presentatie
- `modules/` - Python-modules

## Vereisten

- Python 3.8 of hoger
- Node.js en npm (voor de presentatie)

## Setup

To start the presentation, clone this repo, cd into the subfolder and
start npm i, then start the presentation using npm start

## Gebruik

1. Clone de repository:

   ```bash
   git clone https://github.com/JohnGorter/Python_UnitTesting.git
   cd Python_UnitTesting
   ```

2. Installeer de afhankelijkheden en start de presentatie:

   ```bash
   npm i
   npm start
   ```

## Tests draaien

```bash
python -m unittest discover
```
